# Datasets

No dataset files are bundled with this repository (they are large and/or
license-gated). Download them yourself and place them as described below.
Loaders and schema validators will be built in a later phase to check that
whatever you place here matches the expected format before anything is
used for training.

## CICIDS2017 (primary)

- Source: Canadian Institute for Cybersecurity (CIC), University of New
  Brunswick.
- Place the extracted CSV files in: `ml/data/raw/cicids2017/`

## NSL-KDD (secondary benchmark)

- Source: Canadian Institute for Cybersecurity (CIC) NSL-KDD mirror, or the
  original University of New Brunswick distribution.
- Place `KDDTrain+.txt`, `KDDTest+.txt` (and variants, if used) in:
  `ml/data/raw/nsl_kdd/`

## UNSW-NB15 (generalization / cross-dataset validation)

- Source: Australian Centre for Cyber Security (ACCS), UNSW Canberra.
- Place the CSV files in: `ml/data/raw/unsw_nb15/`

## Notes

- Do not commit raw dataset files to version control (already excluded via
  `.gitignore`).
- Each dataset uses a different attack-label taxonomy. A label-mapping
  document will be created and versioned under `docs/research/` once
  preprocessing begins — attack categories are **not** assumed to be
  identical across datasets.
- `ml/data/processed/` will hold cleaned/engineered outputs generated by the
  preprocessing pipeline — also not committed.
