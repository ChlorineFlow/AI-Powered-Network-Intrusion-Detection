# Research Questions

- **RQ1** — Which model performs best?
- **RQ2** — Does feature selection improve performance?
- **RQ3** — How does class imbalance affect performance?
- **RQ4** — Does deep learning outperform traditional ML?
  (Deferred: deep learning is currently out of scope; this RQ will be
  revisited if/when DL models are introduced.)
- **RQ5** — How well does the model generalize across datasets
  (CICIDS2017, NSL-KDD, UNSW-NB15)?
- **RQ6** — Which model provides the best balance between recall and false
  positives?
- **RQ7** — What is the inference latency?

Every answer to these questions must be traceable to a logged experiment
under `ml/experiments/results/` — no result is reported unless it was
actually produced by running the pipeline.
